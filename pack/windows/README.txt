PokeRogue Co-op: host a game from your PC
==========================================

1. Unzip this folder anywhere (all of it, not just Start.bat).
2. Double-click Start.bat.
   - Windows may warn about a downloaded file: "More info" > "Run anyway".
   - The game opens in your browser, and the window shows a link for your friend
     (already copied: paste it into your chat).
3. In the game: Co-op > Host a game. Send the code to your friend.
4. Your friend opens the link and chooses Co-op > Join a game.

Keep the black window open while you play. Close it to stop.

Good to know
------------
- Your progress is saved in your browser for http://127.0.0.1:8080, so use Start.bat
  the same way next time and it is still there.
- Your friend's link is new every time you start. Their progress is saved for that
  link only: finish a run in one sitting, or play on the website if there is one.
- To continue a saved co-op run, both of you need the same accounts as before, so
  the guest needs the same link: keep the window open between sessions, or start
  a new run.
- Nothing is installed. To remove it, delete this folder.
- Logs are in the "logs" folder if something does not work.
- Only this PC: run "Start.bat -NoTunnel" from a command prompt.
